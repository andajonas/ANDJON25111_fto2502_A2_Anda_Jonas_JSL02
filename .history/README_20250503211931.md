🗂️ Kanban Board

A lightweight, responsive Kanban board built using vanilla HTML, CSS, and JavaScript. Easily manage tasks through a clean drag-and-drop interface without the need for frameworks or external libraries.

✨ Features
✅ Create, edit, and delete task cards

🖱️ Drag and drop between columns (To Do, In Progress, Done)

💾 Saves board state in localStorage

💡 Built with semantic HTML and responsive CSS Grid

📱 Mobile-friendly and adaptable layout

🛠️ Built With
HTML5 – Structure & semantic layout

CSS3 – Styling with Grid and Flexbox

JavaScript – Interactive logic, event handling, and localStorage
